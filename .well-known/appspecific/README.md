Lisää tähän kansioon tiedosto `com.tesla.3p.public-key.pem`.

Saat sen Kipinän käyttöönotosta (Lisää → Käyttöönotto → "Lataa julkinen avain").

Älä koskaan lisää tänne (tai mihinkään repoon) **yksityistä** avainta.
